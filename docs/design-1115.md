# PARALLAX 設計 2026-11-15（11/14 の面談を受けて）

本選の前の最後の大きな作り直しの設計。直す物は八つ。ホーム、詳しく見る、比べる、書体、色、ライトモード、ホームへ戻った時の崩れ、16:9 の発表の表示と電話の幅。

手順は frontend-design の型で進めた。素案を立て、汎用の既定に落ちていないかを見直し、直した。見直しで変えた所は §10 に書く。

元にした物は四つ。
- 面談の記録（11/14）
- 公開版 v53 の撮影。1920×1080・1440×900・390×844 の三つの大きさで、ダークとライトの両方を撮った
- 実在のニュースサービスの実測（2026-11-15 朝）。Yahoo!ニュース・Ground News・AllSides・Google ニュース・NewsPicks
- 既存の裁定。バイアス度は測った値で出す。自分を説明する文を置かない。値の時刻を添える。土台は Apple の静けさで、ホログラムの語彙は少しだけ

この文書では、実物で確かめた事と提案を分けて書く。**未確認**の印を付けた所は、作る時に確かめる。

---

## 0. 一言でいうと

**ホームは「一つの出来事と、一つのグラフ」だけにする。色はデータだけに使い、地は白にする。**

- 一般の人の入口は「何を見られるか」で三つに分ける。日本と海外、片側だけ、偏りの三つ。
- 詳しく見るは 三列の監視卓の構成を残す。流れの帯・タイルの自動スクロール・左右の列の三つ。入れ子のスクロールと、細い字の詰め込みはやめる。
- 比べるは、新聞を横に並べた形にする。行を揃えて、語・数字・反応の語・報じ始めの時刻を横に読ませる。

## 1. 色（トークン）

### 方針
- 色は**意味のある所だけ**に使う。国内・海外・官公庁の三つの側の色と、速報・災害の赤がそれに当たる。UI の差し色は墨（ほぼ黒）一つにする。
- 分野の 7 色（`--g-pol/intl/eco/sec/tech/mkt/oth`、css/app.css:1413）は**やめる**。分野は字とアイコンで見分ける。今は CSS に 16 進の色が 126 種あるので、40 種以下まで減らす。
- 今の選んだ物のシアン（ライトでは `#00739e`）は、海外の藍と見分けにくい。ライトでは墨に替える。ダークは個性のため、選んだ物の縁にだけシアンの発光を残す。これはホログラムの語彙を少しだけ使うという裁定の範囲にあたる。

### ライト
| 名前 | 値 | 役 |
|---|---|---|
| `--win`（地） | `#ffffff` | 頁の地。真っ白にする |
| `--pane`（面） | `#f3f4f6` | 欄・カードの面。墨の 4% 程度の無彩の灰にする |
| `--pane-2`（面の中の面） | `#e9ebef` | 表の見出しの行・押した状態 |
| `--ink` | `#16181d` | 字・UI の差し色（選んだ物・リンクの下線・主のボタン） |
| `--ink-2` / `--ink-3` | `#3d4148` / `#646a73` | 二番目の字・時刻と出典 |
| `--sd-jp` | `#b5235f` | 国内（図・横棒・列の上の線だけ） |
| `--sd-intl` | `#0068a8` | 海外（同上） |
| `--sd-gov` | `#7a5a12` | 官公庁（同上） |
| `--red` | `#d70015` | 速報・災害・古い値 |

- **影は持ち上がった物だけ**に付ける。対象はホームの主役のカード・シート・ポップオーバー。値は `0 1px 2px rgba(16,24,40,.06), 0 12px 32px -16px rgba(16,24,40,.22)` とする。普通の欄には影を付けず、灰の面と地の差で区切る。全部のカードに同じ影を付けると、汎用の型（§10）になるため。
- 字の比（WCAG）は作る時に `--pane` の上で測る。`--ink-3` が 4.5:1 に届かなければ一段濃くする。**未確認**。

### ダーク
今のまま良いという評なので、大きくは変えない。分野の 7 色の廃止と、三つの側の色の使い所の絞りは、ダークにも同じく当てる。

### 「後ろを白・前に色」の根拠
面談で、紺の地に真っ白の面を乗せた今の作りが「スカスカ」に見えるという話が出て、地を白にして面に色を付ける案に決まった。実測した手本でいちばん近いのは NewsPicks で、地は `#fff`、面は墨の 5〜8% の塗り、差し色は一色。Ground News・Yahoo!・AllSides は向きが逆（地が薄い灰・面が白）。ただ、どの手本も**地に色相が無い**点は同じだった。だから決め手は、色の付いた地（今の `#e7edf8`、css/app.css:2769）をやめることにある。

## 2. 書体

### 方針
場所によって書体を変える。字の段は大きさと太さの差で付ける。今の Barlow Semi Condensed（未来的な数字の書体）を画面の全体に撒かない。

| 役 | 書体 | 太さ | 使う所 |
|---|---|---|---|
| 主役の見出し | **Shippori Mincho B1**（明朝） | 600・700 | ホームの注目ニュースの題、比べるの頁の題。**この二か所だけ**に使う |
| 本文・UI・欄の題 | IBM Plex Sans JP | 400・500・700 | それ以外のすべて。欄の題は 700、本文は 400 |
| 図の大きな数 | Barlow Semi Condensed | 300・500 | グラフの中の大きな % と件数だけ。表の数字には使わない |
| 表と時刻の数字 | IBM Plex Sans JP | 400・500 | `font-variant-numeric: tabular-nums` を付ける。等幅の書体は使わない |

- **Zen Kaku Gothic New をやめる**。欄の題の 800〜900 が全部同じ重さで、段が付かない原因になっている。読み込む書体も一つ減る。
- 明朝は「新聞を並べる」という題材から来る選び方で、この製品の一番の主張（同じ出来事を紙面のように比べる）を字で示す。明朝を使うのは主役の見出しの一行だけで、本文には使わない。

### 大きさの段（px・机の上）
| 段 | 大きさ / 行間 | 太さ | 例 |
|---|---|---|---|
| 題 L | 40 / 1.25（電話 28） | 明朝 700 | ホームの注目ニュースの見出し |
| 題 M | 28 / 1.3 | 明朝 600 | 比べるの頁の題 |
| 欄の題 | 20 / 1.35 | Plex 700 | 「日本と海外」「片側だけ」など |
| 見出し | 16 / 1.45 | Plex 700 | 一覧の行の見出し |
| 本文 | 15 / 1.65 | Plex 400 | 要約・説明 |
| 補い | 13 / 1.5 | Plex 400・500 | 媒体名・件数の添え |
| 時刻・出典 | 12 / 1.4 | Plex 400 | 最小の字はこの段にする |

- 実測した手本の段は、Google ニュースが 28/20/14/12、Ground News が 32/22/14/12 で、本文 400 に対して見出しが 800 だった。上の表はこの間に置いた。
- 詳しく見るは、今ほぼ 11〜13px の 600 に揃っている。これを**本文 13〜14px の 400 と、見出し 14〜15px の 700**の二段に分ける。最小は 12px。11px は数字の目盛りだけに使う。
- 大文字の英字のラベルと、題の一語だけを色替えする扱いは使わない。

## 3. ホーム（一般の人向け）

### 見せる物は三つだけ
```
┌───────────────────────────────────────────────────────────┐
│ PARALLAX        11月15日（日） 9:40 更新           ☼ 設定 │  ← 上の帯（値の時刻）
├───────────────────────────────────────────────────────────┤
│ ┌─────────────┐┌─────────────┐┌─────────────┐             │
│ │日本と海外    ││片側だけ      ││偏り          │  ← 大きな入口 3 つ │
│ │ 国内 62%    ││ 国内だけ 4件 ││ 大きい順    │  （各に今の数を一つ）│
│ └─────────────┘└─────────────┘└─────────────┘             │
│  国際 経済 政治 社会 テクノロジー 農業 …   ← 小さな分野のチップ │
│                                                           │
│ ┌──────────── 注目ニュース（主役のカード・影あり）────────┐│
│ │ [写真]  エヌビディア、CEO が辞任                       ││ ← 明朝 40
│ │         国内 18 ・ 海外 41 ・ 官公庁 0   報じ始め 7:12  ││
│ │         ███████░░░░░░░░░░░░░ 国内 31% / 海外 69%        ││ ← 一本の横棒
│ │         [比べる]  [次のニュース]                        ││
│ └───────────────────────────────────────────────────────┘│
│                                                           │
│ ┌──────── 日本と海外の違い（一つのグラフ）──────────────┐│
│ │      国内が多い ◀────┼────▶ 海外が多い                ││
│ │ 政治   ████████│                                       ││ ← 分野ごとの左右の棒
│ │ 国際          │██████████                              ││
│ │ 経済      ████│██                                      ││
│ │ …                         分母 1,240 件・9:40 の値     ││
│ └───────────────────────────────────────────────────────┘│
└───────────────────────────────────────────────────────────┘
```

- **入口は三つ**。名前は「何を見られるか」で付ける。中身の種類（分野）で付けない。
  1. **日本と海外**：開くと、分野ごとの左右の棒のグラフが一つだけ出る（下の図）。分野のチップを押すと、その分野だけで同じグラフになる。主催の「ボタン一つでグラフがガーンと出る」に当たる。
  2. **片側だけ**：国内だけ・海外だけが報じた話の一覧。今の `p-anom`（片側だけのニュース）と `asymmetry` のデータを使う。
  3. **偏り**：バイアス度（0〜100）の大きい順の一覧。押すと内訳が出る。`js/bias.js` の式をそのまま使う。
- 各入口に今の数を**一つだけ**載せる（「国内 62%」「国内だけ 4件」など）。数はデータから計算する。データに無い時はその数を出さない。
- **分野のチップ**は入口の下に小さく一行で並べる。Yahoo!ニュースの二段のタブと、Ground News のトピックのチップを合わせた形にする。押すと、選んだ入口を、その分野で開く。
- **主役のカード**は注目ニュースの一件。見出し（明朝）、側ごとの件数、報じ始めの時刻、**一本の横棒**（国内・海外・官公庁の割合）、ボタン二つ（「比べる」「次のニュース」）を置く。Ground News のカードの下にある割合の横棒にあたる。分母に入らない媒体は数えない。
- **違いのグラフ**は分野ごとに左右へ振れる棒にする（比較は左右に振れる棒、という裁定）。右下に分母の件数と値の時刻を置く。
- 色は棒と横棒の三つの側の色だけに使う。入口のカードは灰の面にして、色を塗らない。

### ホームから外す物
- 注目度ランキング・片側だけの大きな欄・時間別の件数・媒体の数の帯は、詳しく見るへ移す。片側だけの中身は入口 2 の先に置く。
- 題の下に説明の文は置かない。主役のカードの「両方」の欄に、文の途中から切った断片が出ている（v53 で確認）。これは出さない。要約が文として閉じていない時は欄ごと畳む。
- ホームでは自動の送り（12 秒ごと）を**止める**。主役のカードは、「次のニュース」を押した時だけ替わる。下の帯の出典が、自動で送られた別の媒体を指してしまう件（v53 で確認）も、これで消える。

### 電話（390）
- 入口三つは、画面上部の横に並んだタブ（横スワイプでも替わる）にする。分野のチップはその下で横にスクロールさせる。
- 主役のカードの写真は上に置き、見出しは明朝の 28px にする。違いのグラフは縦の棒に変えず、横の棒のまま分野を縦に並べる。
- 「ホーム画面に追加」の案内は、15 秒後に一覧の上に被さる（v53 で確認）。これを最初の操作の後の下端に移し、被せない。

## 4. 詳しく見る（詳しい人向け）

### 方針
三列の監視卓の構成の分かりやすさ（主催の評）を残す。ホームを少し詳しくした版を土台にする。詰まり・被り・入れ子のスクロールをなくす。

```
┌──────────────────────────────────────────────────────────────────┐
│ 流れの帯：取得した媒体が横に流れる（取れた／取れない）  9:40 更新  │
├───────────────┬────────────────────────────────┬─────────────────┤
│ 注目ニュース   │ 選んだニュース                  │ 数               │
│ ・行 × 8      │  見出し（Plex 700 20）          │  国内/海外/官公庁 │
│ （絞り込みは   │  横棒・側ごとの件数・報じ始め   │  の表と最終更新   │
│   一行）       │  [比べる]                        │  媒体の積み上げ   │
│               │ ─────────────────────────────── │  時間別の件数     │
│               │  写真のタイル（自動スクロール） │  バイアス度と内訳 │
│               │                                  │                  │
├───────────────┴────────────────────────────────┴─────────────────┤
│ 下の段：片側だけ ｜ 映像（16:9・幅 ≥ 320px） ｜ 地図 ｜ 市場 ｜ 政治 │ ← 横に並べ、各段は畳める
└──────────────────────────────────────────────────────────────────┘
```

- **三列にし、各列のスクロールは一度だけ**にする。列の中に、さらにスクロールする欄を入れない。今は中央の列の中の入れ子のスクロールの下（y≈5806）に、映像の欄が埋まっている。
- **注目ニュースの絞り込みの札は一行**にする。今は 3 段で、欄の半分を取っている。分野の選択は一つのボタンからのポップオーバーに移す。
- **映像は下の段に出す**。幅は最小 320px、16:9 で 180px 以上にする。今は 1440 の幅で 148×83px で、題が切れていた。映像の画面（`#video`）は、開いただけで広告が鳴り始めた。**自動再生をやめ**、押してから再生する（`autoplay=0`、再生は消音で始める）。
- **右の列は数の表**にする。Ground News の記事の頁の Coverage Details に倣い、媒体の数・国内・海外・官公庁・最終更新の行を置く。今の右の列は、「市場」が見出しだけに潰れ、「政治」の文が行の途中で切れている。そこで市場・政治・地図は下の段の横並びに移し、各段に最小の高さを持たせる。
- 中央の「媒体の比べ」だけが 48px の極太になっている。これを欄の題の段（20px・700）に揃える。
- 関連ニュースの「つながり」は、一文字ずつ縦に折れていた。ラベルの欄に `min-width` を与え、狭い時は上に回す。
- 欄の数：一度に開いているのは九つまでにする（流れの帯・三列・下の段の五つ）。残りは「表示」のメニューから出す。

### 自動スクロール
- 中央の写真のタイルだけを自動で流す。注目ニュースの自動の選び替えは、**詳しく見るの時だけ**動かす。動かし方は §8 の (b) にする。
- `prefers-reduced-motion` の時は流さない。

## 5. 比べる（同じニュースを新聞のように並べる）

```
┌──────────────────────────────────────────────────────────────────┐
│ エヌビディア、CEO が辞任                       （明朝 28）         │
│ 媒体 59 ・ 9:40 の値                                              │
├────────────────────┬────────────────────┬────────────────────────┤
│ ▬ 日本の報道 18     │ ▬ 海外の報道 41     │ ▬ 官公庁 0（無ければ列ごと畳む）│ ← 列の上に色の線
├────────────────────┼────────────────────┼────────────────────────┤
│ 注目した語          │                     │                         │ ← 行を揃える
│  辞任 12 調査 7 …   │  probe 22 resign 19 │                         │
├────────────────────┼────────────────────┤                         │
│ 出てきた数字        │                     │                         │
│  3年 ・ 2,000億円   │  $4.2T ・ 3 years   │                         │
├────────────────────┼────────────────────┤                         │
│ 反応の語（語の数）  │                     │                         │
│  批判 3 ◀█│▶ 歓迎 0 │  批判 9 ◀██│█▶ 支持 2│                         │
├────────────────────┼────────────────────┤                         │
│ 報じ始め  7:12      │  3:48（3時間24分 先）│                         │
├────────────────────┼────────────────────┤                         │
│ 見出し              │                     │                         │
│  媒体名  見出し 時刻 │  媒体名 見出し 時刻  │                         │
│  …（5 件・残りは「すべての記事」）       │                         │
└────────────────────┴────────────────────┴────────────────────────┘
```

- **行を揃える**のがこの画面の要になる。目を横に動かせば、同じ項目が日本と海外でどう違うかが読める。主催の「抽出して、数字・グラフ・横棒でパッと違いが見える」に当たる。
- 色は**列の上の線とラベル**だけに使い、中の文は墨にする（AllSides の Headline Roundup の作法）。
- **注目した語**：見出しから語を数える。`coverage.json` の語の表（`roles`・`events`・`orgs`）で拾い、上位 5 語に件数を添える。
- **出てきた数字**：見出しに出た金額・人数・期間を抜き出す。片方にしか無い数字は、印を付けて目立たせる。
- **反応の語（肯定・否定）**：真偽も立場も判定しない。`coverage.json` の `react` の語を、否定の側（批判・反発・非難・懸念 など）と肯定の側（歓迎・支持 など）に分けて**語の数を数える**だけにする。左右に振れる棒の下に「見出しの語の数」と書く。どちらかの側の語が 3 未満なら棒を出さない。AI に読ませて出す場合は、裁定どおり印を付けて分ける。**肯定・否定の側の語の分け方は、今の表にまだ無い**ので、足す（下の §9）。
- **報じ始め**：側ごとに最も早い時刻と、その差を出す。
- 見出しは各列 5 件までにして、残りは「すべての記事」で開く（Google ニュースの全報道の作法）。
- 記事が少ない時は、数を出さない。片方の列が 2 件未満なら、その列の抽出の行は「記事が少ないため出しません」の一行にする。
- 電話の幅では二列を横に並べられない。上に「日本／海外」の切替を置き、行ごとに二つの値を上下に重ねた差の行で見せる。列を切り替えても、同じ行の高さに留まる。

## 6. ライトモード

- 地は `#ffffff`、欄は `#f3f4f6`、主役のカードだけ白に影を付ける（§1）。今と逆の向きになる。
- ホームの最初の一枚に**面を敷く**。今は青みの地の上に、字が直に乗っている。
- 下の帯は白の 60〜84% の欄（`--hs-fill`、css/app.css:2775）をやめて、`--pane` の不透明の塗りにする。
- 主役の欄は、写真が無い時に左の約 4 割が空く。写真が無い時は**見出しを全幅**にし、側の件数の大きな数を左に置く。
- 比べるのカードの写真は、中央の 6 割しか埋まらず灰の帯が出る。`object-fit: cover` で全幅にする。
- **不具合**：主役の欄の地名の札（`.lk.banner`）が、白の地に白の字で読めない。css/app.css:3011 でライトの地だけを白にし、字の色は css/app.css:1578 の `#fff` のまま残っているのが原因。ライトの時は字を `--ink` にする。
- 電話のライトで、読み上げの球が黒い円盤に見えて重い。ライトでは `--pane-2` の面に墨のアイコンを乗せる。

## 7. 分け方の言葉（画面の文言）

- 入口は「日本と海外」「片側だけ」「偏り」の三つ。ボタンは「比べる」「次のニュース」「すべての記事」「詳しく見る」。同じ操作には、どこでも同じ言葉を使う。
- 画面に、自分を説明する文・標語を置かない。数と時刻と見出しで語る。
- 空の時の文は一文で、次にできる事を書く。例：「国内だけの話は今ありません。分野を替えると出ることがあります。」
- 数には必ず値の時刻を添える（「9:40 の値」）。値が古い時は赤にし、取れない時は「未取得」と出す。

## 8. ホームへ戻った時の崩れの直し方

v53 で再現を確かめた。原因は二つの穴が重なったことにある。

1. **スクロールが戻らない**：ホームと詳しく見るは、同じ `#board` を共有している。ホームでは `#board` 自身がスクロールの箱になる（css/app.css:2796）。ところが `setHome`（js/app.js:1514-1524）と `goScreen`（js/app.js:1507-1512）は、`#board.scrollTop` を戻していない。ロゴを押した時の `window.scrollTo(0,0)`（js/app.js:1746、1759）は頁全体を動かすだけで、`#board` には届かない。
2. **自動の送りがホームを下へ運ぶ**：`autoStep`（js/app.js:2217-2228）が 12 秒ごとに `select` を呼ぶ。そこで js/app.js:2112 の `scrollIntoView({block:'nearest'})` が、親の `#board` まで動かす。実測では、手を触れないまま 1600→1444、2123→1646 と動いた。

直し方：
- (a) **画面ごとにスクロールの位置を分ける**。詳しく見るからホームへ移る時は `$('board').scrollTop = 0` にする。詳しく見るの位置は、`state.boardScroll` に覚えて、戻った時に返す。ロゴ・ホームのタブ・ブラウザの戻る・使い方の終わりの四つの経路は、すべて `setHome` を通す。
- (b) **2112 の `scrollIntoView` をやめる**。`#pri-b` の中だけを、`pri-b.scrollTop` の計算で動かす。親の箱は動かさない。
- (c) **ホームでは自動の送りを止める**（§3）。ホームへ戻った時は、主役のカードを注目ニュースの一件目に揃える。
- (d) ハッシュが替わったら、つながりの窓（`netClose`、js/app.js:3486）を閉じる。今は閉じるのボタンと Esc でしか閉じない。

確かめ方：下までスクロールして詳しく見るへ行き、四つの経路で戻る。それぞれ 30 秒待って、`#board.scrollTop` が 0 のまま動かず、主役が一件目である事を測る。三つの大きさとダーク・ライトで行う。**スクロールしてからブラウザの戻るで帰る組は、まだ試していない**。

## 9. 16:9 の発表（`?show`）と電話の幅

### 発表（1920×1080、`?show`）
- ホームは**一画面に収める**。入口三つ・主役のカード・違いのグラフが、スクロールせずに見える事を条件にする。主役の見出しは 56px（明朝）、グラフの棒のラベルは 24px 以上にする。会場の後ろから読める大きさにするため。
- `?show` の時は、使い方の案内・「ホーム画面に追加」・自動再生・自動の送りをすべて出さない（`isShow()`、js/stage.js）。
- 詳しく見るは三列と下の段で一画面に収める。下の段は二つまで開き、残りは畳む。
- 比べるは二列（日本・海外）を全幅で、抽出の行を五つ見せる。

### 電話（390×844）

- 入口はタブ、主役のカード、違いのグラフ（§3）の順に置く。詳しく見るは一列にして、流れの帯 → 選んだニュース → 数 → 下の段の順に積む。
- 押せる的は 44px 以上にする。

## 10. 見直し（汎用の既定に落ちていないか）

素案から変えた所を書く。

1. **素案では、ライトの面を全部白のカードにして同じ影を付けていた**。どの製品にもある「同じ角丸のカードに同じ灰の影」の型で、どこかで見た画にしかならない。→ 面は無彩の灰の塗りにし、影は主役のカードとシートだけに限った。角丸も段で替える（主役 16px・欄 10px・チップ 999px）。
2. **素案では、比べるを細い罫線の密な紙面の段組みにしていた**。題材は「新聞を並べる」だが、罫線と角丸 0 の段組みは、ありふれた新聞風の既定になる。→ 段組みは行を揃えた格子だけにし、罫線は使わない。列の区切りは色の線（列の上の 3px）と余白で付けた。
3. **素案では、差し色に今のシアンを残していた**。→ ライトで海外の藍と見分けられないので、UI の差し色を墨にした。色はデータだけに使う、という一つの約束で統一する。
4. **素案では、数字とラベルを等幅の書体にしていた**。等幅の小さなラベルはよくある既定の印。→ Plex の表用の数字（`tabular-nums`）に替え、未来的な数字の書体は図の大きな数だけに残した。
5. **素案では、入口に 01・02・03 の番号を振っていた**。入口は順番ではない。→ 番号を外し、各入口に今の数を一つ置いた。

大胆にする所は一つに絞る。**主役の見出しの明朝**がそれで、周りは静かにする。
