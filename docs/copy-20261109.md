# 文言の前後の一覧（2026-11-09）

作り手の命令（原文）：「『詳しい画面で開く』→『詳しく見る』のように文言をすべて修正しろ」「『同じニュースを、国内と海外のメディアと官公庁がどう伝えたか。並べて比べます。』こういう説明もいちいち文言がAI　ダサい」「ホームに戻ると、簡単表示がどのように違うのかっていうのがちょっとわかりにくいよね」「よく報じられているみたいなのも、報じられてるってことは注目されてるってことだろう。…文言をちゃんと分かりやすい一言で分かるようなのを目指せ」。

直し方：`design:ux-copy` に沿って、(1) 同じ操作は同じ名前、(2) ボタンは動詞か行き先、(3) 説明の文・標語・宣伝の型は消すか事実を一文に、(4) 外来語はカタカナのまま（窓・釦・札・盤・画に寄せない）、(5) 題名は数え方でなく読む人にとっての名前。置き換えは正確に一致した文字列だけ（`tools` ではなく一回限りの台本）で行い、英語表示（`js/i18n.js`）の見出しの語は同じ置き換えで一緒に動いた。件は置き換えた箇所の数。

## 2. 説明文（サイトが自分を説明する文・宣伝の型・AI 調の言い回し）

消した物・事実だけの一文にした物。直した後の文は、声に出して読んで不自然でないかで判じた。探した型：「〜を、〜が〜したか。〜します。」の説明／「〜できます」「〜を一目で」「〜をまとめて」／体言止めを並べる宣伝／「A・B・C」の中黒で売る型／「〜から〜まで」／不要な主語／疑問で引く見出し。
