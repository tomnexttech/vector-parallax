# 場所のトレンドのデータ源（2026-11-22）

地図で選んだ場所の「流行・SNS」に使う源と、使わない源。画面は `js/trend.js`（ニュースの集計）と `js/trendui.js`、SNS は `parallax/social.py` が作る `data/social.json`。

## 1. 使っている：Bluesky の公開検索

| 項目 | 内容 |
|---|---|
| 口 | `GET https://api.bsky.app/xrpc/app.bsky.feed.searchPosts`（認証なし）。`q`・`lang=ja`・`since`・`until`・`sort=latest`・`limit=100` を使う。返りの `hitsTotal` が、その検索に当たった投稿の数 |
| 取り方 | **ブラウザから直に叩かない**。3 時間ごとの GitHub Actions（`update.yml` の「Social data」の段、`python -m parallax.extras --only social`）が取り、集計だけを `data/social.json` に書く。頁はその同じ場所のファイルを読むだけ（CSP の `connect-src` は変えない） |
| 場所 | `data/social_places.json` の 65 か所（47 都道府県・渋谷・新宿・池袋・横浜・川崎・名古屋・札幌・仙台・神戸・北九州・主な 7 つの国と地域）。ここに無い場所の SNS は集めていない（画面もそう言う）。足す時はこのファイルへ |
| 1 回の量 | 1 場所につき検索 6 回（直近 12 時間を 3 つ、その前の 24 時間を 3 つに時間で切る）。65 か所で約 390 回、3 か所ずつ並べて約 4 分。0.4 秒の間を置く |
| 規約 | 利用規約 https://bsky.social/about/support/tos （2026-11-22 に読んだ）に、自動の読み取り・検索 API・公開投稿の分析を禁じる条項は無い。同じ規約は、投稿の権利は投稿者にあること、Bluesky の知的財産に権利を与えないことを述べる。このためこの源は**集計の数だけ**を残し、投稿の本文・利用者の名前（ハンドル・DID）・リンクは保存も表示もしない。検索 API の呼び出し数の上限は、読めた公式文書（https://docs.bsky.app/docs/advanced-guides/rate-limits）に公開の検索の項が無く、確かではない。同じ文書の「ホスト別」の例は IP ごとに 5 分で 3000 回なので、その 1/7 以下に収まる量にした |
| 確かめた振る舞い（2026-11-22） | ①`public.api.bsky.app` は 403（2026-11-11 の記録と同じ。`parallax/reaction.py` の `not_used` はこの口を指していた）。`api.bsky.app` は認証なしで 200。②**2 ページ目（`cursor` 付き）は 403「Request forbidden by administrative rules」**。このため 1 回の検索で取れるのは新しい側の 100 件だけで、窓を時間で 3 つに切って、それぞれの 100 件を標本にした。③`hitsTotal` は 1 万で頭打ち（その時は `capped` を立てて「以上」と出す）。④口が変わる・閉じる可能性は常にある：1 場所の失敗は理由つきの行になり、6 か所続けて失敗したら残りを止め、全部失敗したら前のファイルを残す |
| 作る数 | 件数（`hitsTotal`）・直近とその前の 1 時間あたり・増えている言葉（片仮名・漢字・英数・#タグ。5 投稿以上・3 人以上・直近の標本の 4 割以下・前より 1.5 倍以上）・肯定否定（`data/sentiment_ja.json` の語の表に当たる投稿の数。皮肉と否定形は読まない。表はこのリポジトリの作者が書いた小さな物で、外の辞書の写しではない） |
| 標本の偏り（画面に一行で出す） | Bluesky の日本語の投稿だけで、世論の縮図ではない。検索は投稿に語が含まれる物を探すだけ（京都が東京都に当たる等の誤りは `precision` に測って、9.5 割を切れば画面に書く） |

## 2. 使わない：X（旧 Twitter）

読み取りが有料の従量制で、無料の読み取りの枠が公式の料金ページに無い（https://docs.x.com/x-api/getting-started/pricing、`parallax/reaction.py` の記録は 2026-11-11）。**使わない**。金額は契約の画面で決まるため、ここには書かない（出典の無い数を置かない）。つなぐ時は、(1) 月の上限を決める (2) 65 か所 × 8 回 ≒ 520 回/3 時間 ≒ 4,000 回/日 を目安に費用を見積もる (3) 利用規約の「表示・再配布」を読み直す、の順。
