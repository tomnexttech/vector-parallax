# 画面の幅に収まる・一本の指で地図を動かす（v47）

報告（2026-11-09）：iPad では、表示している画面の幅に収まっているのに、横スクロールが画面そのものを表示幅の外まで許してしまう。iPhone の横画面は見にくい。iPhone など指での地図の操作がしにくい。

## 1. iPad の横ずれ

### 元

比べる（と、ニュースの詳細、出来事の頁）の表（`table.cv-t`、メディアごとの見出しを並べた表）は、自分の箱 `.cv-sc` の中だけで横に流れる作り。ところが狭い箱では、
表の中の「点だけの印」の本文（`.cv-p`、読み上げ用に見えなくした `position: absolute` の要素）が **表の箱の外**（一番近い `position: relative` の箱 = 上の `.cv-wrap`、
出来事の頁では文書そのもの）を基準に置かれ、箱の `overflow` で切られず、表の幅（約 1600px）の分だけ外側の領域の幅を広げていた。
外側の領域（比べる = `section#entry`、ニュース詳細 = `#nw-case`）は `overflow: auto` だったので、指で横に引くと中身だけが左へ動く（報告された画面の「中身が左へ約 4 割ずれる」）。
出来事の頁（`s/<sid>.html`）は文書そのものが 400〜680px 横へ流れた。

### 直し方（元から）

* `.cv-sc` に `position: relative`（出来事の頁の CSS も同じ）= 箱の中に置いた物は箱の中で切られる。流す箱は `overscroll-behavior-x: contain` と `touch-action: pan-x pan-y` を持つ。
* 上下に流れる領域（`.entry`・`.sect`・`.nw-l`・`.nw-r`・`#case`・`.pb`・`.cb`・`.about`・設定・自分の AI の窓・検索の一覧・地図の一覧など）は `overflow-x: hidden` と `overscroll-behavior-x: none`。
* `html` は `overflow-x: hidden; overflow-x: clip`（clip を知らない古い iOS には hidden）、`overscroll-behavior-x: none`、`-webkit-text-size-adjust: 100%`（横向きで文字が勝手に大きくならない）。
  `body` も `overflow-x: hidden`。**body ごと隠すだけにはしていない**（元を直したうえの二重の備え。流す表・列は自分の箱の中で流れる）。
* 試験：`tests/js/overflow_css.test.js`（この規則が CSS に有る事）、`tools/overflow_check.mjs`（Chrome に iPad / iPhone の画面・タッチ・UA を与えて、頁×幅で「文書の幅 = 表示の幅」「指で動く箱 0」「指で横に引いた後に動いた物 0」を数える。
  `node tools/overflow_check.mjs --site _site --sizes 820x1180,1180x820,844x390p`、`tests/js/overflow_browser.test.js` は `PLX_SITE_DIR` と Chrome があるときだけ走る）。

### 数（頁×幅）

各欄は「文書の余りの幅 / 指で横に動かせる上下の箱の数 / 指で引いて実際に動いた数」。`0` は 3 つとも 0。`-` は読めなかった欄。
読み方：iPad 縦（768・820・834・1024）と横（1024・1180・1194・1366）、Chrome の端末の真似（モバイル・タッチ・iPad の UA）、公開データ（2026-11-09 の公開版）で、
スワイプは横へ 400px を 3 か所（画面の右・中・左）で行った。

## 2. 地図の一本指（js/map.js・js/mapgl.js・js/mapui.js・js/floor.js・js/touchmode.js）

元：地図は「小さい箱」のとき（ページの途中・幅 1280px 以下は全部）MapLibre の協調操作（`cooperativeGestures`）で **二本の指** でないと動かなかった。
地図の画面（#map）の中でも同じで、iPhone の横向きでは地図の画面に地図が出ず（地図の枠が隠れ、ニュースの列だけ）、押すと拡大の札は 1281px 以上でしか出なかった。

* **地図が画面そのものの所**（地図の画面・横向きの iPhone の地図の枠・開いた全画面の地図）では、**一本の指で動く**。二度たたいて拡大、二度たたいて押したまま上下になぞって拡大・縮小、二本の指のつまみ。
  地図は `touch-action: none` で、ページは流れない。＋／−のボタンは 44px（地球儀のボタンも 44px 以上）。
* **ページの途中に載る小さい地図**（詳しく見る・ホームの下の地図の箱）は **見本**：指はページのスクロールに使われ（`touch-action: auto`）、**押す（タップ）と画面いっぱいの地図が開く**
  （`<html data-mapfull>`、押した出来事の丸があればその丸の札も）。閉じるのは左上の「閉じる」（44px）・Esc・別の画面へ移る事。開いた地図は `role="dialog"`、閉じるにフォーカスが移る。
* 判定は `js/touchmode.js` の `touchLive()`（試験 `tests/js/touchmode.test.js`）。マウスの操作は元のまま（小さい地図の拡大は Ctrl＋ホイール）。出来事の丸を押すと札が開く働き・押す／なぞるの区別（動いたらなぞる、動かなければ押す）はそのまま。
* WebGL が無い端末の描画（canvas の地図）にも、一本指の移動・二度たたき・二度たたいて上下を入れた。
* 測定（Chrome の端末の真似・タッチ・iPhone／iPad の UA、CDP `Input.dispatchTouchEvent`）：

| 場面 | 一本指のなぞり（中心） | 二度たたき（倍率） | 二度たたき+下／上（倍率） | ページ（scrollY・box） |
|---|---|---|---|---|
| iPhone 縦 390×844・地図の画面 | 経度 −23.0°・緯度 −10.3°動く | +1.00 | +0.63 / −0.63 | 動かない |
| iPad 縦 820×1180・地図の画面 | −116°・−1.3° | +1.00 | +0.63 / −0.63 | 動かない |
| iPhone 横 844×390・地図の画面（左に列・右に地図 503×318） | −122.9°・−4.4° | +1.00 | +0.63 / −0.63 | 動かない |
| iPhone 縦・詳しく見るの小さい地図を指でなぞる | 地図は動かず、ページが 105px 流れる（見本） | – | – | 流れる |
| iPhone 縦・小さい地図を押す | 全画面の地図が開く（376×822） | – | – | – |
| iPhone 縦・開いた地図 | −23.8°・−12.3° | +1.00 | – | 動かない（閉じるで戻る） |
| iPad 縦・開いた地図 | −11.1°・−5.6° | 0（測定では拡大せず。地図の画面では +1.00。＋／−のボタンは使える。実機で要確認） | – | 動かない |

## 3. iPhone の横画面（css/app.css の末尾、`@media (orientation: landscape) and (max-height: 500px) and (max-width: 1100px)`）

* 帯：上の帯 40→36px、その下の件数の帯 50→28px、枠の見出しの帯 45→38px（押せる高さは疑似要素で 44px を保つ）、下の出典の帯 24→22px。
* 分野：背の高い丸い札（縦に積んだ 80px）を、**一本の行の小さな札**（高さ 32px・押せる範囲 44px・横に流れる）にした。件数の行（`#pri-chips`）は畳んだ。
* ニュースの画面：大きな見出し帯（50px）をやめ、タブ・分野・件数の下に **見出しが 2 本** 並ぶ（前は 1 本）。
* 地図の画面：左に場所のニュースの列、右に地図（前は地図が出なかった）。地図の上の層の列・分野の列は 1 行ずつ横に流れる形、＋／−・地球儀は右下。
* ノッチの側の余白は `.app` の `env(safe-area-inset-left/right)`（元から）と、開いた地図の `env(safe-area-inset-*)`。`dvh` は元から（`.app` は `100dvh`）。
* 文字：`-webkit-text-size-adjust: 100%` を足した（横向きで文字が勝手に大きくならない）。タッチ端末の入力欄は 16px（iOS が入力で画面を拡大しない）。分野の札は 13px、件数の帯は 12px 以上。
* 撮影：`J_handoff/東京AIハッカソン2026_提出/画面/50_design/v7_mobile/`（iPhone 横 667×375・844×390・852×393・932×430 の ホーム・詳しく見る・比べる・ニュース・地図、iPad 横 1180×820、地図の一本指の撮影）。
