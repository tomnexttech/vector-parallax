# 見方（総合サイト）と市場の見方（2026-11-22・v90）

## 1. 見方の分け方

PARALLAX は一つのサービスの名前でなく、入口（`#portal`）から三つの見方に分かれる総合サイト。今ある画面は一つも消していない。

| 見方 | 何を出すか | 中の画面（今までの名前のまま） |
|---|---|---|
| ニュース比較 | 同じニュースを国内・海外・官公庁がどう伝えたか | ホーム・詳しく見る・比べる・ニュース・政治・映像 |
| 地域 | 場所から、起きている事とその土地の話題 | 地図（v89 の地域の話題を含む）・災害 |
| 市場 | 金利・為替・商品、と株の過去の確率 | 経済指標・株の確率 |

- 入口は新しい訪問者と、名前（Parallax）を押した時に出る。一度見方を選んだ人は次から最後の見方へ直接入る（このブラウザだけ・`parallax.view.v1`）。`?portal=1` で必ず入口、`?portal=0` で入口なし。ブースの `?demo=1` と、出来事を指すアドレス（`?sid=` `?t=`）は入口を通らない。
- 上の帯（`.tb`）は畳んだ: 1100px 超ではホーム・詳しく見る・比べるの切替と、各区画のリンクを帯から外し、その下の「見方の帯」（見方の三つ＋開いている見方の画面）に移した。1100px 以下の PC・タブレットも同じ。スマホは下の列（ニュース・地図・保存・その他）をそのまま残し、見方の帯を上に足した。
- 初回のツアー（js/tour.js）は、入口が先に出た時は、最初にホームを開いた時に始まる。
- 実装: `js/portal.js`（見方の定義・入口の判定）・`js/portal_ui.js`（入口と帯）・`js/sections.js`（`portal` と `stocks` を末尾に追加。Alt 1〜8 は変えない）。

## 2. 株の確率（市場の見方）

入れたのは一般向けにできる部分だけ（`js/stocks.js`・`js/stocks_ui.js`）。

- 銘柄の日足から数えた**過去の確率**: 信号（売られすぎ RSI(14)<30・55 日高値の更新・上昇基調）ごとに、日数・**独立な場面の数**・20 営業日後に上がっていた割合・95% の区間（独立な場面での Wilson）・どの日でも上がっていた割合（基準）との比べ。独立な場面が 10 未満の信号は割合を出さない。画面の横に、生存者バイアスと限界の四行を常に置く。
- **ニュースと値動きの結び付け**: 訪問者が入れた言葉を見出しに含むニュースが初めて出た日の、終値の前日比（と 4 営業日後）を数える。原因とは言わない（同じ日の別の出来事と区別できない旨を同じ画面に書く）。
- 色は上昇=緑・下落=赤、必ず ▲▼ を添える。値には値そのものの日付（最後の終値の日）を付け、4 日を超えて古ければ「N 日前の値」と赤で示す（取得時刻を値の日付に見せない）。
- 売買の勧め・個別の助言・「買い時」の類は書かない（試験が語を見張る）。作り手の持ち株・注文・資産は入っていない（私用の株の道具は私用のまま。ここは別実装で、そのデータも読まない）。

### 株価はこのサイトが持たない

公開サイトで日足を**表示・再配布してよいと原文で確かめられた配信元が 0 社**だった（2026-11-22 調査、下の表）。そこで、サイトは株価を持たず、次の二つだけで動く。

1. 訪問者が自分の日足（日付と終値の CSV。日付・始値・高値・安値・終値の形も可）を読み込む。ブラウザの中だけで数え、送信も保存もしない（`fetch`・`localStorage` を使わない試験あり）。
2. 「見本で見る（架空の値）」: 種を固定した乱数の値動き。「架空の値・実在の銘柄ではありません」と画面に書く。

将来、配信元を契約した時のための門が `parallax/stocks.py`（`data/stocks.json` の契約）。各系列に、配信元の名前・規約のページ・読んだ日付・「公開ページでの表示を許す」の記録が無ければ `validate` が断る。今は何も書かない（CI にも組み込んでいない）。

### 金融機関へ売り込む形

機関が自分のライセンスのデータを持ち込む（BYOD）形にすると、PARALLAX 側は価格データを保管・再配布しない。注意点: ①提供元ごとに「社内利用のライセンス」を第三者の画面に出してよいかが違う（Twelve Data・Tiingo・EODHD は契約者以外への表示を禁じる）。②キーをその機関の閲覧者だけに見せる形にし、書面で確かめる。③J-Quants の個人プランと FRED の指数系列は持ち込み対象から外す。紹介の一枚は `PARALLAX事業\03_会社紹介と実演\PARALLAX_市場の見方_紹介.html/.pdf`。

## 3. 確かでない所

- 日足の読み込みは CSV のみ。機関のデータ形式（API・Excel）への対応は未着手。
- 信号は三つだけ。私用の道具で八つの信号を測った時に有意だったのは売られすぎ一つだけだった。ここでは再現していない（見本は架空の値）。
- 実機（iPhone・iPad の Safari）は見ていない。headless Chrome の端末幅の描画で見た。
- 読み上げ（NVDA・VoiceOver）は未確認。
