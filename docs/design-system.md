# PARALLAX デザインの体系（2026-11-08・方向 B「写真と余白」＋ C のガラスと光を移動の層だけ）

手本と理由は `docs/design-research.md`。実装は `css/app.css` の冒頭の `:root` と、末尾の「design system 11-08 b」の節。

## 0. 原則（三つ）

1. **内容が主役、枠は引く**：欄は角の丸い面と 8px の間で区切る。線は表の行の間だけ。
2. **一件に大きな数は一つ**：ニュース一件で大きく出すのは「媒体の数」だけ（Barlow Semi Condensed 300）。
3. **光るのは選んだ物の縁だけ**：選んだニュース・区画・カードに 1px の水色の縁。ダークではごく弱い光を足し、ライトでは縁だけ。

## 1. 色

意味の無い色を足さない。三つの側の色はデータの印（棒・点・小さな四角）にだけ使う。赤は速報・災害・読めなかった時だけ。

| 名前 | 用途 | ダーク | ライト |
|---|---|---|---|
| `--win` | 頁の地 | `#000000` | `#f5f5f7` |
| `--pane` | 欄の面 | `#1c1c1e` | `#ffffff` |
| `--raise` | ボタンの面 | `#2c2c2e` | `#ffffff` |
| `--raise-h` | ボタンの面（指した時） | `#3a3a3c` | `#f2f2f4` |
| `--ink` | 字 | `#f5f5f7`（15.6:1） | `#1d1d1f`（16.8:1） |
| `--ink-2` | 二番目の字 | `#c3c3c8`（9.7:1） | `#424245`（10.0:1） |
| `--ink-3` | 補いの字・時刻 | `#98989f`（5.9:1） | `#6e6e73`（5.1:1） |
| `--ink-4` | 飾りと使えない物だけ（字に使わない） | `#6c6c72` | `#8e8e93` |
| `--cyan` | 選んだ物・フォーカス・リンク | `#64d2ff`（9.9:1） | `#00739e`（5.3:1） |

比は `--pane` の上での値（WCAG のコントラスト比）。本文の字は 4.5:1 以上。

**作り手の好みの三色（白・シアン・赤）を一般向けに少しだけ**：白＝地と字の主（ダークの字・ライトの地）、シアン＝選んだ物の縁と大きな数のごく弱い光だけ、赤＝起きた時だけ。三色とも面を塗らない。

## 2. 書体

| 役 | 書体 | 太さ | 使う所 |
|---|---|---|---|
| 見出し `--f-display` | Zen Kaku Gothic New | 700・900 | 区画の題、ニュースの見出し、かんたん表示の題 |
| 本文と UI `--f-text` | IBM Plex Sans JP | 400・500・600 | 一覧・表・ボタン・説明 |
| 数字 `--f-num` | Barlow Semi Condensed | 300・400・500 | 件数・時刻・％（tabular） |

大きさの段（`--fs-0`〜`--fs-10`）：10・11・12・13・14・16・19・22・34・44・60px。本文の最小は 12px（`--fs-2`）。11px 以下は数字の目盛だけ。
行間：見出し 1.3〜1.4、本文 1.6。見出しの字間は 0（詰めない）、大きな数は −0.02em。
大文字の英字のラベル、見出しの一語だけの色替えは使わない。

## 3. 余白

4 の倍数：`--sp-1` 4・`--sp-2` 8・`--sp-3` 12・`--sp-4` 16・`--sp-5` 24・`--sp-6` 32・`--sp-7` 48。
ボードの欄の間と外周は 8px。欄の中は 12〜16px。かんたん表示の段の間は 32〜48px。

## 4. 角の丸み

階層で替える。同じ丸みを全部に使わない。

| 名前 | 値 | 使う所 |
|---|---|---|
| `--r-s` | 6px | ボタン・入力・小さなラベル |
| `--r-m` | 10px | 一覧の行の選択・小さな写真 |
| `--r-l` | 14px | 欄・カード |
| `--r-xl` | 20px | シート・先頭の写真 |
| `--r-pill` | 999px | 分野の切替・言葉の粒 |

## 5. 素材（ガラス）

HIG に従い、ガラスは**移動と操作の層だけ**。

| 層 | 素材 | 場所 |
|---|---|---|
| 移動の層 | regular のガラス（ぼかし 24px・彩度 180%・縁 1px・上辺の弱い光） | 上の帯、スマホの下の列、シート、検索の欄、ポップオーバー |
| 内容の層 | 不透明の面（`--pane`） | ボードの欄、カード、図、表 |
| 写真の上 | 使わない（写真に字を重ねない） | — |

「透明度を下げる」（`prefers-reduced-transparency`）では、ガラスを不透明の面に替える。

## 6. 図の色

- 件数の比：三つの側の色の積み上げの棒（一本）。値は字の色で、横に数と％。
- 時間の流れ：線と面は `--ink-2` の一色、注目の点だけ `--cyan`。
- 市場：一色（`--ink-2`）。上がり下がりは数の色だけ。
- 地図：描き方は変えない。地と字の色だけ変数に合わせる。

## 7. 動き

- 押した物の答えだけ動かす（開く・選ぶ・閉じる）。頁を開いた時の飾りの動きは無し。
- 長さ：短い 120ms（指した時）、中 220ms（選ぶ・開く）、長 320ms（シート）。`--ease` は `cubic-bezier(.16,.84,.28,1)`。
- `prefers-reduced-motion` と設定の「動きを減らす」では止める。

## 8. 部品の要点

- **上の帯**：ガラスの帯。選んだ区画は字を `--ink-hi` にし、下に 2px の水色の線（ダークでは弱い光）。
- **欄**：`--pane` の面・`--r-l`・欄の頭は同じ面の上に見出しの書体 14px 700。頭の下の線は無し。
- **選んだ行・カード**：1px の水色の縁（`--lit-box`）。左の太い線は使わない。
- **かんたん表示**：題は 34px 900。カードは写真 4:3・見出し 3 行・割合の棒。選んだニュースの頭に媒体の数を大きく一つ。
- **シート**：ガラスの頭（`.sheet-h`）、本文は不透明。

## 9. 残り（この版で済まなかった事）

- 方向の見本のスマホ（390）は Chrome のウィンドウの幅の下限で右が切れて写った。見本としては左半分で判断した。製品の 390 は `shot_design.mjs` の端末の幅で撮った。
- 1024 前後のタブレット・iPhone の実機は見ていない。
- 地図の区画の色は変数の色だけ追った。地図の描き方には触れていない。

## 10. 三つの方向の比べ（design-critique）

見本は `東京AIハッカソン2026_提出/画面/50_design/directions/`（A・B・C の home・simple を 1440 と 390、`sheet_*.png` は並べた物）。

| | A 紙面の品格 | B 写真と余白 | C ガラスの層と光 |
|---|---|---|---|
| 最初の 2 秒 | 明朝の大見出し。新聞と分かる | 先頭の写真と大きな数 | ぼかした写真の色とガラス |
| 比べる数の読みやすさ | 棒は細く、字に負ける | 大きな数＋棒で一目 | 大きな数は強いが、背景の色が数を食う |
| ダーク | 弱い（紙の比喩が崩れる） | 地と字を替えるだけで同じ骨組み | 強い。ライトは弱い |
| HIG との合い | — | 合う | 内容の層にガラス（HIG に反する） |
| 中立の床 | 合う | 合う | 報道写真を頁の色に使う（反する） |
| 生成の型 | 「細い線の紙面」の型に近い | 「同じ角丸のカード」に寄る危うさ | 「暗い地に差し色一つ」に寄る |

**選んだ物：B**。理由は、裁定（Mac の美しさが土台）と HIG に合い、比べる数が一番早く読めるため。B の危うさ（同じ角丸のカードの羅列）は、角の丸みを階層で替え（6・10・14・20）、影を使わず、選んだ物の縁だけを光らせて避ける。C からは「移動の層のガラス」「縁だけが光る」「大きな数の弱い光」の三つだけを借りた。A・C は見本のまま残す。

作った後の点検（`50_design/` の after_*）：
- 良くなった：欄が 8px の間の角の丸い面になり、線の格子が消えた。見出しの書体で区画の頭とニュースの見出しが本文から離れた。数字が細い計器の数字になり、横幅が少し空いた。図のタイルの水色の枠と角の印を外し、光るのは選んだ物だけになった。
- 残る：ボードの骨組み（4 列）は変えていない。ホームは今もボードで、B の見本の「先頭の写真が大きい」ホームにはなっていない（機能と配置を変えない約束のため）。次の版でホームの左上を先頭の一件に充てる案を検討する。

| 補いの字（ダーク） | #98989f | #1c1c1e | 5.9 | 4.5 | 可（前の #75787d は約 3.9 で不可だった） |
| 補いの字（ダーク・ボタンの面） | #98989f | #2c2c2e | 4.9 | 4.5 | 可 |
| 補いの字（ライト） | #6e6e73 | #ffffff | 5.1 | 4.5 | 可 |
| 補いの字（ライト・頁の地） | #6e6e73 | #f5f5f7 | 4.7 | 4.5 | 可 |
| 水色（ライト） | #00739e | #ffffff | 5.3 | 4.5 | 可 |

- タッチの的：スマホの下の列 54px、かんたん表示のボタンとカードは 44px 以上（前のまま）。PC の上の帯のボタンは 26px（ポインタ向け・WCAG 2.2 の 24px は満たす）。

## 12. 文言（ux-copy）

文言は変えていない。点検だけ：かんたん表示の頭の一行・「ニュースを押すと、下に伝え方の違いが出ます」・「詳しい画面へ」は、押すと何が起きるかを言えている。AI のまとめに英単語が混じる（例：emphasize）のはデータ側の問題で、画面の文言ではない。

## 13. 次の版 v2（作り手の選択：B と C の合わせ）：作り方の案

第一段は色と書体だけで、見た目の変化が小さかった。v2 はホームの配置から作り直す。画は `東京AIハッカソン2026_提出/画面/50_design/v2/`。

1. **ホーム（見本 B の配置）**：`.board` の 4 列の骨組みをホームでやめる。
   - `.col` を `display: contents` にして欄を平らにし、`.board` を `grid-template-areas` で組み直す（欄の id は `index.html` から読む）。
   - 上の段：左に先頭の一件（出来事の欄 `#case` を大きな写真・見出し・媒体の数を一つだけ大きく・各側の細い棒に）、右に「ほかのニュース」（注目の欄 `#pri-b` を写真つきの縦の列に）。
   - 下の段：ランキング・一部の媒体だけ・地図・災害・市場・政治・映像・まとめた見出し・媒体・時間ごとの見出し・分野を、高さが中身に合うカードの面で 3〜4 列に並べる（頁はスクロールする）。
   - 今のボードは「詳しい画面へ」で開く（例：`html[data-home="board"]`、prefs に保存）。機能は減らさない。
2. **C のガラスと光**：移動の層（上の帯・スマホの下のタブ・シート・検索・ポップオーバー）のガラスは第一段で済み。足すのは、頁の地のごく薄い光の場（`body` に CSS の放射グラデーション 2 つ：左上に水色 6%、右下に白 4%。ライトは 3% 以下）と、内容のカードを半透明の薄い面（ダーク `rgba(28,28,30,.72)`、ガラスのぼかしは掛けない）にすること。報道写真はぼかして地に使わない（中立の床）。
3. **写真の無いニュース**：灰色の面をやめ、分野の記号（js/genres.js）を分野の色の薄い面の中央に置く。
4. **かんたん表示・出来事の画面・390** を同じ体系で揃える。スマホは上の段を縦に積み、先頭の一件の写真は 4:3。
5. 撮影：`shot20.mjs` の j の段で、1440 ダーク・ライト・390。`.tb` に backdrop-filter を掛けるとスマホで下のタブが上へ移る（固定の箱になる）ので、761px 以上に限る今の作りを崩さない。

### 13-b. 追加の裁定（11/8 作り手「グラスモーフィズム入れてね。」）：ガラスを見た目の主役に

§5 の「ガラスは移動の層だけ」と §13-2 の「内容のカードはぼかさない」を改める。作り手の指示が HIG より優先される。手本は `J_handoff\入力盤_デザイン_1108\v3\` と `J_handoff\参考画像\グラスモーフィズム_1108\`（ファイルのまま見る）。
- **頁の地**：CSS のグラデーションで抽象の色と光の場を作る（報道写真はぼかして地に使わない）。ダークは深い色の光（紺・深い青緑・ごく弱い赤紫を 2〜3 個の放射で）、ライトは明るい淡い光。真っ黒・真っ白の地にしない。
- **層は 3 段**：地 → 大きな面（区画・ホームの上の段）→ カード。上の段ほど少し明るく、ぼかしを強くする（例：大きな面 `blur(24px) saturate(160%)`・カード `blur(32px) saturate(180%)`）。上の縁に 1px の細い光（`inset 0 1px 0 rgba(255,255,255,.14)`）、柔らかい影、角 18〜22px。
- **読みやすさ**：字の下の面を濃いめにして 4.5:1 を保つ（ダークの面 `rgba(22,24,30,.62)` 前後から測る）。`prefers-reduced-transparency` と `prefers-contrast: more` では不透明に戻す。
- **重さ**：ぼかしは大きな面の単位だけ。行・ラベル・小さなボタンの一つ一つには掛けない。長い一覧が中でスクロールする欄は、ぼかしを外して半透明の塗りにする。iPhone と iPad の Safari で確かめる。
- **選んだ物**：白く満ちる、または縁が光る。差し色は三つの側の色と赤（速報・災害）だけ。
- **点検**：`50_design/v2/` にダーク・ライト・390。ガラスに見えるか（ただの灰色の板になっていないか）を目で見る。


## 14. v2 の実装記録（2026-11-08・B と C の合わせ、ガラスを主役に）

画は `東京AIハッカソン2026_提出/画面/50_design/v2/`（`v2_home_dark`・`v2_home_light`・`v2_home_390`・`v2_simple_dark`。`_top` は先頭、`_low` は下へスクロールした所）。実装は `css/app.css` の末尾「home v2」の節、`js/app.js` の `setHome`・`rowThumb`、`index.html` の `#home-bar`。

### 14-1. 作った物

- **頁の地**：CSS だけの光の場。深い紺・青緑・赤紫の放射 4 つと、縁のはっきりした円 3 つ（`body::before`、`position: fixed`）。円の縁が大きな面の裏でぼけて見えるので、ガラスだと一目で分かる。報道写真は地に使わない。
- **層**：地 → 大きな面（リードのニュース・注目の一覧・下の段の各カード、ぼかし 20〜26px・彩度 160〜165%・上辺に 1px の光・柔らかい影・角 24〜30px）→ 面の上のタイル（写真・行・数字。平らな半透明の塗りでぼかしは掛けない）。
- **ホーム**：上に大きな題「今日のニュース」、左にリードの 1 件（写真は縁を切らずに全体、見出し、媒体の数を 60px の細い数字で一つ、国内・海外・官公庁の細い棒と件数）、右に注目の一覧（4:3 の小さな写真か、写真が無ければ分野の記号を分野の色の薄い面の中央に）。その下にカードを 3 列（1700px 以上は 4 列）。順は「よく報じられている → 一部の媒体だけ → 地図 → 災害 → 政治 → 市場 → 映像 → 集めた見出し → 媒体 → 時間ごとの見出し → 分野」。
- **詳しい画面**：今のボードをそのまま残した。上の帯の「詳しい画面」（開くとボード、押すと「ホームに戻る」）、題の横の「詳しい画面へ」、リードの「詳しい画面で開く」と媒体の数から開ける。かんたん表示の「詳しい画面へ」もボードへ行く。選びは `parallax.home.v1`（このブラウザだけ）、初回の描画前に `js/theme_boot.js` が `<html data-home>` を立てる。
- **かんたん表示**：同じ地の上に、カードを同じガラスの面にした（`.en-card`・`.en-col`）。
- **スマホ（760px 以下）**：1 列。リード（写真を先頭）→ 注目 → カード。下の段のカードはぼかしを掛けず、平らな半透明の塗りにした（スマホの描画の重さを避ける）。横向きの小さな画面（高さ 500px 以下）は今の配置のまま。
- **透明度とコントラスト**：`prefers-reduced-transparency` と `prefers-contrast: more` で、地の光を消して不透明の面（`--pane`）に戻す。`backdrop-filter` の無いブラウザも不透明。
- 動き：押した物への答え（120ms の面の明るさ）だけ。`prefers-reduced-motion` で止める。

### 14-2. 使った 4 つのスキルと変えた点

1. **frontend-design**：作る前に、案を汎用の既定（暗い地に差し色一つ、同じ角丸のカードの羅列、上の飾りの英字ラベル）と照らした。変えた点：地の光を「ぼけた円」でなく縁のはっきりした円にして裏のぼけを見せる／角丸を 12・18・24・30 と階層で替える／大文字の英字ラベルと見出しの一語だけの色替えは使わない／見出しは 700、頁の題だけ 900／数字は細い 300。
2. **design-critique**：撮影した画を、手本（入力盤 v3・参考画像のガラス）と並べて見た。最初の版は面が濃い灰の板で、円の色が透けず「ただの灰色の板」に近かった。変えた点：面の塗りを黒の半透明から、斜めの白い光の層＋薄い暗色（ダーク）／白の層（ライト）にして、縁と上辺の光を足した。円の芯の明るさを落とし（`#3a5ce0` → `#2e49bb`）、字の下のコントラストを守った。リードの見出しが 5 行になり下が切れたので、リードの本体を内容の高さにして見出しを 31px・700 に下げた。写真の無い 1 件だけ、リードの下半分が空く（残り）。

## 15. v2b（2026-11-08・v2 を main へ合わせる前の直し）
