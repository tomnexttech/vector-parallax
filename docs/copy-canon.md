# 見出しの文言の決まり（2026-11-15d）

見出し・入口・タブ・欄の題・ボタンの名は、`js/heads.js` の一つの表から取ります。英語の訳も同じ表から引きます（`js/i18n.js` は表を先に見ます）。`tests/js/heads.test.js` が、表の全ての見出しがこの決まりを守っているか、昔の文の形の見出しがコードと `index.html` に戻っていないかを確かめます。新しい画面を足す時は、見出しを先にこの表へ足してから使います。

## 決まり

- 見出しは **2〜8 字の名詞** にする。漢語の複合語かカタカナ語で、一目で掴める札にする（国内外比較・日本独自・海外独自・偏り度・初報・分野別）。
- **助詞（の・と・を・が・は・に・で）でつながない**。漢字・カタカナ・英字の隣に助詞があれば文の形とみなす。かなだけの語（つながり）の中のかなは数えない。
- **「〜の話」「〜について」「〜を見る」「〜する」を付けない**。説明が要るなら、見出しでなく数と図で語る。
- 例外は一つだけ。媒体を押すと開く面の名「媒体の特徴」は、作者が名付けた言葉なのでそのまま使う（`HEAD_KEEP`）。
- 画面に自分を説明する文を置かない（「〜を並べて比べます」の型）。ボタンは動作を短く（「詳しく見る」「比べる」「読み上げ」）。同じ操作は同じ言葉で通す。
- 文言は ux-copy の型（明確・簡潔・一貫）で点検する。
